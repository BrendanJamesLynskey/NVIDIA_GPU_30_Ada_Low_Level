# Inside Ada Lovelace — AD102, 96 MB L2, 3rd-Gen RT

A low-level deep dive into NVIDIA's 2022 Ada Lovelace architecture. AD102 through AD107 dies on TSMC 4N, the doubled-FP32 SM with 4th-gen tensor cores (FP8 E4M3 / E5M2 exposed across the entire Ada line, with datacenter Ada — L40S / L40 / RTX 6000 Ada — marketing the FP8 throughput), 3rd-gen RT cores with opacity and displaced micro-meshes, the Optical Flow Accelerator and DLSS 3 frame generation, the 96 MB L2 cache jump, GDDR6X up to 23 Gbps, the 12VHPWR / 12V-2×6 power-connector saga, and the consequences of dropping NVLink from the consumer line. Includes an interactive Ada SKU picker.
